# Local Windows time-service queries

This package owns the bounded W32Time QueryStatus exchange.
The Windows connector checks the pipe server against the running service process before it sends a request.
`QueryStatus` accepts an already checked stream, owns it, and closes it after the exchange.

The RPC client receives one fixed stream through its dialer hook. It cannot select another address or reconnect.
The reader limits each fragment to 16 KiB and the full reply to 64 KiB.
It checks allocation hints before decoding and preserves the observation deadline when the client changes stream deadlines.

The connector reads service state and uses the local `W32TIME_ALT` pipe with caller identification.
It grants no permission to act as the caller. It starts no service and changes no time setting.
Cancellation bounds the caller's wait. One process-wide slot limits native service-manager calls that cannot accept a context.
That slot remains occupied until the outstanding query returns and releases its resources.

After the peer check, the connector requests the service principal on the same pipe.
A successful empty reply selects a null SSPI target for this verified local endpoint. A failed query still refuses authentication.
Windows SSPI authenticates the process identity through Negotiate with packet privacy and identification-only access.
The connector rejects unavailable authentication and insufficient security flags. It never retries status without authentication.
Native handles close after each observation, including failed exchanges.
The security library loads from the Windows system directory only. No provider credential or password enters this exchange.

The RPC transport performs no DNS lookup and opens no network socket.
Windows authentication policy can require domain services. The observation deadline and worker limit also cover authentication waits.
The reader permits bounded authentication trailers without changing its fragment or total reply limits.
Native tests check encryption, changed headers, changed payloads, changed signatures, replay refusal, and handle cleanup.
GitHub Actions retains local privilege information and a separate `w32tm` status query for native diagnosis.

Microsoft documents this protocol in [W32Time product behavior](https://learn.microsoft.com/en-us/openspecs/windows_protocols/ms-w32t/bb576d39-587b-484a-86a4-e1d378cf9497).
The bindings follow [the Windows SDK SSPI declarations](https://github.com/microsoft/win32metadata/blob/main/generation/WinSDK/RecompiledIdlHeaders/shared/sspi.h).

This package reports status. The parent hostclock package owns source profiles, timestamp units, and UTC uncertainty.
