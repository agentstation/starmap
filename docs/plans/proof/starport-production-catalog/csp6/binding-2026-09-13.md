# CSP6 receipt binding

Commit `528b5890b107f0174a232e7b1638d41e7c0c4529` binds admitted source evidence to validated artifact contents.
The [verification record](binding-2026-09-13/verification.json) binds two files to eight check results and their original output.

`BindReceipt` repeats admission before it creates a receipt.
It opens the artifact and verifies its detached statement, manifest, payload, and candidate semantic checksum.
The receipt names the actual generation, semantic checksum, payload checksum, and archive checksum.
Rejected admission, invalid artifact bytes, checksum mismatch, and cancellation return no receipt.

The binding digest covers compact `encoding/json` bytes for the complete validated acquisition binding, without a newline.
Public receipts expose the binding identity, revision, provider, and digest.
They omit account, project, region, API surface, and credential-profile selectors.
Tests change each private selector and require a different digest without exposing the value.

The unchanged-artifact test creates distinct fresh and retained run receipts over the same immutable artifact.
It preserves the original observation identity for retained evidence and leaves the artifact bytes unchanged.
A repeated identical run produces identical receipt bytes and checksum.
