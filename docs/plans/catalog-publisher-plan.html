Catalog publisher plan

Status: active · Owner: this plan · Created: 2026-09-01 · Baseline: main @ 42b610a · Proof root: docs/proof/catalog-publisher/ · Next action: store 11 provider secrets and update the six-hour workflow

Outcome

Starmap refreshes its catalog every six hours with available acquisition credentials, publishes a verified catalog resource, supports a verified latest-catalog pull path, and releases the completed behavior.

Progress

The status ledger supplies progress.

Architecture

Scope

Owns: provider credential inventory, repository Actions secrets, publisher cadence, catalog discovery, verification, import, publication proof, and the next Starmap release.

Does not own: Starport inference credentials, Starport source changes, provider account creation, or a hosted deployment.

Non-goals: change catalog authority, expose secret values, weaken release verification, or call inference endpoints.

Invariants

  1. No secret value enters Git, logs, plans, proof files, or replies.
  2. The workflow exposes provider credentials only to its refresh step.
  3. Catalog acquisition never uses Starport account or gateway secrets.
  4. A failed refresh cannot replace the last verified catalog resource.
  5. A Starmap instance verifies catalog bytes before activation.
  6. The release requires protected main, and Starport's existing worktree stays unchanged.
