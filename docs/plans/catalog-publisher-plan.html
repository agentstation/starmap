Catalog distribution plan

Status: proposed. Owner: this plan. Created: 2026-09-01. Baseline: main @ 42b610a, publisher work @ 7247a002. Proof root: docs/proof/catalog-publisher/. Next action: get owner answers for CAT-D2 through CAT-D5, then activate CAT2.

Outcome

Starmap publishes one verified public catalog channel and consumes it by default in connected package, server, and container runtimes. A configured Starmap catalog source replaces the public source. Starport instances can share an enterprise Starmap source without public GitHub egress.

Progress

The status ledger supplies progress.

Architecture

Scope

Owns: publisher credentials and cadence, catalog names, the public channel, GitHub verification, and catalog-source contracts.

The plan also owns connected runtimes, application defaults, source cascading, Starport adoption, migration guidance, proof, and releases.

Does not own: provider inference credentials, provider account creation, a managed AgentStation Starmap deployment, or enterprise network and storage provisioning.

Non-goals: do not change provider fact authority without an owner decision. Do not expose secrets or trust mutable tags. Do not require GitHub CLI in a Go consumer.

Invariants

Security and trust

  1. No secret value enters Git, logs, plans, proof files, or replies.
  2. The workflow exposes provider credentials only to its refresh step.
  3. The mutable channel can select only an immutable verified catalog release.
  4. Every activation verifies publisher identity, bytes, schema, and generation order.
  5. A failed source retains last-known-good state and reports degradation.

Runtime behavior

  1. A configured enterprise source causes no undeclared public GitHub fallback.
  2. The low-level catalog client remains safe for deterministic offline use.
  3. Starport validates a complete runtime candidate before acceptance.
  4. Existing catalog releases remain immutable and readable.
  5. Each background lifecycle has one owner and a bounded shutdown.

Decisions

CAT-D1, accepted 2026-09-01: New releases use catalog-<digest>, discovery uses catalog-latest, and only technical checksum fields use semantic terminology.

CAT-D2, pending owner: Keep starmap.New as the offline primitive, and add starmap.Open as the connected application default.

CAT-D3, pending owner: A configured catalog source replaces public GitHub without an implicit fallback.

CAT-D4, pending owner: Reconcile the source below a local human catalog workspace, while Starport exactly follows the selected Starmap generation before runtime acceptance.

CAT-D5, pending owner: Poll the public GitHub channel hourly with jitter and conditional requests, and follow Starmap through SSE.

CAT-D6, provisional engineering selection: Use sigstore-go directly behind a Starmap-owned GitHub identity policy and transport adapter, subject to CAT2.1 evidence and GitHub CLI parity.
